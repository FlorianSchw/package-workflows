# Contributing

Thanks for your interest! Feedback is very welcome — **please open an
issue rather than a pull request** for now.

This repository has no branch model or review rules yet, so pull requests
can't be handled properly and may be closed without review until that is
set up.

Before opening an issue, have a look at the
[roadmap and open questions](https://florianschw.github.io/package-workflows/roadmap.html)
— your point may already be listed there.
